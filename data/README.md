# Dataset folder

This folder is a template for storing your own image dataset.

Structure:

- images/ : place your JPG/PNG files here
- labels.csv : CSV file with image_name, caption, and language

Example row:

image_name,caption,language
sample_1.jpg,"A person sitting at a table with a cup and a book","English"

Add your own images in the `images` folder and update the CSV file to match.
